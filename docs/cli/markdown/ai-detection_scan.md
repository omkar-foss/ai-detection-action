## ai-detection scan

Scan commits for AI signals

```
ai-detection scan [repo-path] [flags]
```

### Options

```
      --format string           output format: json or text (default "text")
  -h, --help                    help for scan
      --min-confidence string   minimum confidence level: low, medium, high (or 1, 2, 3) (default "low")
      --range string            commit range in BASE..HEAD format
```
